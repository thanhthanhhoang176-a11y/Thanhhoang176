# Danh sách câu để tạo giọng đọc

Mỗi câu tạo thành **một file riêng**, đặt tên 01.mp3, 02.mp3... theo thứ tự. Mỗi file nên **ngắn hơn hoặc bằng thời lượng tối đa** ghi bên cạnh (nếu dài hơn, mình sẽ ép nhanh lên, nghe bị gấp). Nếu giọng đọc dài hơn, hãy tăng tốc độ đọc một chút ở dịch vụ.
